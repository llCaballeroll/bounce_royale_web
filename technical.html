Sistemas del Juego

Bounce Royale combina físicas simples, control táctil, progresión visual y mecánicas competitivas para mantener partidas rápidas y adictivas.

🕹️ Control One-Tap

Sistema de entrada táctil diseñado para que el jugador controle saltos y rebotes con una interacción sencilla.

🧱 Colisiones

Lógica de rebote, obstáculos, paredes y detección de impacto para generar tensión en cada movimiento.

🔥 Modo Fever

Mecánica especial que premia la precisión del jugador al encadenar rebotes y activar momentos de alta intensidad.

🎁 Recompensas

Sistema de monedas, cajas misteriosas, cartas, skins y progresión para incentivar la repetición de partidas.

Arquitectura del Proyecto

Estructura modular para separar el núcleo del juego, pantallas, servicios, economía, tienda, audio y persistencia local.

lib/ ├── main.dart // Punto de entrada, configuración inicial y arranque de servicios ├── game/ // Núcleo del juego y lógica Flame │ ├── components/ // Player, obstáculos, paredes, monedas, power-ups │ ├── systems/ // Colisiones, física, spawning, fever, score │ └── managers/ // GameManager, ArenaManager, MatchManager ├── screens/ // Menú principal, juego, tienda, ajustes, game over ├── services/ // Ads, compras, audio, storage, analytics, restore purchases ├── models/ // Skin, reward, loot box, player profile, purchase item ├── ui/ // Widgets reutilizables, botones, cards, overlays └── l10n/ // Internacionalización y textos por idioma

Patrones de Diseño

  • Component-Based: entidades separadas para jugador, obstáculos, recompensas y elementos de arena.
  • Service Layer: servicios independientes para anuncios, compras, audio y almacenamiento.
  • Overlay UI: separación entre lógica Flame y pantallas Flutter para menús, tienda y ajustes.

Optimización

  • Object Pooling: reutilización de obstáculos y efectos para evitar picos de memoria.
  • Asset Optimization: imágenes comprimidas y audio optimizado para cargas rápidas.
  • Mobile Performance: ajustes para mantener fluidez en dispositivos de gama media.
