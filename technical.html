The foundation

Game engine

Flame runs the match: the ball, the spiked pipes, the coins and Fever Mode are game components. Adventure Mode and VS Mode are two separate Flame games.

Interface

Flutter draws the home screen, the Trophy Road, the shop, settings, the tutorial and the VS podium, using the Anton font with a black outline like in the game.

Boxes and cards

Each box gives 5 cards; each card is drawn from the 16 box skins with the same probability. The odds are shown in the app.

Sharing

The record card is drawn on the phone, saved as a temporary image and shared with the system share sheet.

Project structure

Game logic lives apart from the interface, and external services have their own folder.

lib/
├── main.dart              // startup, languages and ads
├── game/
│   ├── world/             // Adventure Mode and VS Mode
│   ├── components/        // pipe and coin
│   ├── managers/          // pipe spawning
│   ├── box_loot.dart      // boxes, cards and rarities
│   └── progression.dart   // level skins every 50 points
├── services/              // ads, purchases and sound
├── ui/
│   ├── screens/           // home, levels, shop, settings, tutorial
│   └── widgets/           // odds, record card, VS podium
└── l10n/                  // translations

Privacy by design

  • No sign-up: no name, email or phone number.
  • Local progress with shared_preferences; it's deleted when you uninstall the app.
  • No own server: the developer receives no match data.
  • Google AdMob with UMP consent and a "Privacy options" button in Settings.
  • Apple and Google process purchases; Game Center and Google Play Games keep the leaderboard.
